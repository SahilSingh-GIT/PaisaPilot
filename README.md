# PaisaPilot

PaisaPilot is a full-stack personal finance and expense tracking application. This project was built to automate our daily financial tracking and 'start the game' of managing money better!

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** Prisma ORM (with PostgreSQL/MySQL)

## Setup Instructions

1. Clone the repository
2. Run `npm install` in both the `client` and `server` folders.
3. Create `.env` files based on `.env.example` in both folders.
4. Run `npx prisma db push` in the server directory to set up the database schema.
5. Start the backend with `npm run dev` in the `server` folder.
6. Start the frontend with `npm run dev` in the `client` folder.

Enjoy tracking your finances!
